# Plans

Checked-in implementation plans live here as:

`docs/plans/{id}-{kebab-slug}.md`

- `id` is a monotonic integer (zero-pad to three digits below 1000)
- No category symlink tree — keep the folder flat
- Link other plans with stable paths like `docs/plans/001-short-title-plan.md` as a naming example only — do not create a broken link to a missing file

See [`../skills/plans-template.md`](../skills/plans-template.md).
