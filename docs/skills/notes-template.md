# Notes template

Use topic-based filenames under `docs/notes/`. Prefer updating an existing
notes file over creating a new one.

```markdown
# <Topic> notes

## <Issue title> — YYYY-MM-DD — open|resolved

**Summary:** one or two sentences

**Symptom:** what broke or confused

**Repro:** minimal steps / fingerprint

**Root cause:** … or `TBD`

**Fix / status:** …

**Verification:** proven | unverified | not run — how

**Related:** links to README.md, methodology.md, curriculum.md, plans
```
